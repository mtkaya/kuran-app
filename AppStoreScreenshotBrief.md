# Kuran App - App Store Screenshot Design Brief

## 📱 Technical Requirements

**Required Dimensions (iPhone 6.5" Display):**
- Portrait: **1242 x 2688 px** or **1284 x 2778 px**
- Landscape: **2688 x 1242 px** or **2778 x 1284 px**

**File Format:** PNG or JPEG (no alpha)
**Color Space:** sRGB
**Number of Screenshots:** 3 (minimum) - 10 (maximum)

---

## 🎨 App Brand Guidelines

### Color Palette
| Color | Hex Code | Usage |
|-------|----------|-------|
| Primary Dark | `#0a0f1a` | Background |
| Gold Accent | `#d4af37` | Highlights, active states |
| Emerald Green | `#10b981` | Secondary accent |
| Soft White | `#f8fafc` | Text |
| Muted Gray | `#64748b` | Secondary text |

### Typography
- **Arabic Text:** Traditional Quran font (Uthmani script)
- **UI Text:** Inter or SF Pro (iOS system font)

### Design Style
- Dark mode primary
- Glassmorphism effects
- Subtle Islamic geometric patterns
- Premium, minimalist aesthetic

## 📝 General Design Tips

1. **Use device frames sparingly** - Apple prefers clean screenshots without thick bezels
2. **Add headline text at the top** - Brief, impactful feature callouts
3. **Maintain consistency** - Same color palette and style across all screenshots
4. **Show real content** - Use actual Quran text, not placeholder text
5. **Localize if needed** - Screenshots can be localized for each App Store region
