## English (en-US)

```
• Verse cards: turn any verse into a shareable image with nine backgrounds.
• Complete transliteration: all 6,236 verses across all 114 surahs now show a reading. Previously only some did.
• The Arabic typeface is now bundled, so it renders correctly offline.
• Various fixes and improvements.
```

## What actually changed

- Verse card sharing — a renderer with nine code-drawn backgrounds and a
  share sheet (`39dbcb3`, `fa5da20`)
- The Amiri Quran face is bundled rather than fetched from a CDN, so Arabic
  renders correctly with no network (`2444a90`)
- The transliteration corpus is complete: 114 surahs / 6236 verses in both
  the Turkish and Latin readings, replacing a 45-verse sample. This closes
  the reader report that readings stopped after Bakara 5 (`f3f3e18`)
- The basmala is prefixed onto ayah 1 wherever the Arabic carries it, so the
  two lines agree on screen (`de5a972`)
- The "no transliteration for this verse" notice no longer flashes on a cold
  open while the corpus chunk is still loading (`980391c`)
- Sources screen credits Açık Kuran (CC BY-NC-SA 4.0) for both readings and
  Tanzil for the Latin spelling convention (`46e08ee`)
- iOS MARKETING_VERSION corrected from 1.0.7 to 1.0.8 (`e81c0c2`)

## Before uploading

```bash
git pull
npm run test:run
npm run build
npx cap sync
```

Android Studio → Build → Generate Signed Bundle / APK → **Android App Bundle**
(not APK). If Gradle rejects the JDK:

```bash
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
```

Confirm the bundle is signed before uploading:

```bash
jarsigner -verify -verbose android/app/release/app-release.aab | tail -3
```
