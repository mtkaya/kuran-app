## What actually changed

- The last-read ribbon defaulted to `top: 1rem / right: 1rem`, inside the
  mushaf header's footprint. The header is `z-50` against the ribbon's
  `z-30`, so the flag and settings buttons painted over the label — it read
  "OKUNAN" with the gear on top. Moved below the header rather than raised
  above it, which would have covered the buttons instead. A ribbon placed by
  long-press keeps its own coordinates.
- Nine call sites set `fontFamily: arabicFont` with nothing after it. Only
  `Amiri Quran` is bundled; the other six faces come from the Google Fonts
  CDN and one from jsDelivr. Offline, the declaration resolved to whatever
  the OS provides for Arabic. `arabicFontStack()` now appends the bundled
  face and a generic, so the worst case is the wrong style rather than the
  wrong renderer. This is the rule `verseCard.ts` already applied to canvas.
- `scripts/capture-store-screenshots.mjs` produces the store screenshots from
  the production build at 1290×2796, so they can be regenerated per release
  instead of rebuilt by hand.

Not a defect, recorded because it was first reported as one: the bundled
`Amiri Quran` subset covers all 70 Arabic codepoints `ar.json` uses. Boxes
seen during capture came from the capture container having only DejaVu,
FreeSerif and Unifont for Arabic — not from the app.

## Before uploading

```bash
git pull
npm run test:run
npm run build
npx cap sync
```

**Android** — Android Studio → Build → Generate Signed Bundle / APK →
**Android App Bundle**. If Gradle rejects the JDK:

```bash
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
```

Confirm the bundle is signed:

```bash
jarsigner -verify android/app/release/app-release.aab 2>&1 | grep -iE 'verified|unsigned'
```

**iOS** — Xcode → **Any iOS Device (arm64)** → Product → Archive → Distribute
App → App Store Connect → Upload. The archive must read **1.0.9 (10)** with
identifier `com.arfhause.kuran.multilang`; that identifier is correct and
must not be changed to match `capacitor.config.ts` (see the comment there).
